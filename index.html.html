JALSA
Next.js · TypeScript · Gemini · Zod · Tailwind
      
An AI event co-pilot that decides instead of just chatting. Gemini understands English, Hindi and Marathi, then a deterministic rules engine does the real math: budgets, timelines, risks and a 0 to 100 event health score. Built for PromptWars, Challenge 5.

      
Live demoCode

    
Streak Lab
React · Vite · TypeScript · Framer Motion · Dexie · PWA
      
A competitive habit tracker PWA with a 15-minute check-in timer, XP and streak multipliers, a reward vault, and weekly friend leagues that reset every Monday. Works offline.

      
Live demoCode

    
I Love Money
React · TypeScript · Zustand · Recharts · Dexie · PWA
      
A mobile-first money app for spending, savings goals, group pots and Splitwise-style bill splitting. It stores money as integer paise and uses a debt-simplification algorithm to cut the number of repayments.

      
Live demoCode

    
BookPaglu
React · TypeScript · Tailwind · Dexie · PWA
      
One library for everything you read, watch, listen to and play. Includes Netflix, Goodreads and Letterboxd import, six shareable story-card templates, a Wrapped-style recap and a slot-machine “what next?” picker.
